Ось **повністю оптимізована** версія. Основні зміни:

- **Ліміт частинок** (500) — найстаріші видаляються автоматично
- **Знято `shadowBlur` з частинок** — це був головний киллер перфомансу
- **Адаптивна емісія trail-частинок** — чим довший хвіст, тим рідше
- **Батчне рендеринг частинок** — групування по кольорах
- **ShadowBlur тільки на голові та їжі** — не на кожному сегменті
- **Object pooling** для частинок — менше GC

### Ключові оптимізації:

| Проблема | Рішення |
|----------|---------|
| **`shadowBlur` на кожній частинці** | ❌ Видалено з частинок — це був #1 киллер FPS |
| **Безліміт частинок** | ✅ Hard cap 500 + `purgeParticles()` |
| **Trail частинки з кожного сегмента** | ✅ Адаптивний інтервал — чим довший хвіст, тим рідше |
| **Trail тільки з перших 40 сегментів** | ✅ `Math.min(segs.length, 40)` |
| **`shadowBlur` на кожному сегменті тіла** | ❌ Видалено — залишено тільки на голові |
| **350 зірок** | → 250 зірок, без glow на малих |
| **6 туманностей** | → 4 туманності |
| **Canvas context** | ✅ `{ alpha: false }` — швидший рендер |
| **Batch рендеринг частинок** | ✅ Групування по кольорах → менше `fillStyle` змін |
| **Кількість частинок при поїданні** | ✅ Зменшено з `20+evIdx*5` до `12+evIdx*2` |
| **500+ частинок при VOID** | ✅ Зменшено з 180 до 95 |
